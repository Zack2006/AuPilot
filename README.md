# AuPilot

AuPilot 是一套面向长期黄金持有者的本地化策略辅助系统。它基于完整的黄金 UTC 日线行情提供低频战术调仓建议、未来概率观察和条件价格预期，同时保留长期持仓视角。

> AuPilot 仅提供分析与决策辅助，不自动下单，不连接券商，也不承诺收益。

## 核心功能

- **黄金市场**：展示黄金日线 OHLC、移动均线、布林带和本地技术指标，支持图表缩放与可见窗口分析。
- **决策助手**：展示当日战术建议、未来 21 个有效日线槽的顶底概率，以及不控制交易动作的条件 OHLC 价格预期。
- **宏观雷达**：基于官方公开来源提供独立的五档宏观风险提示；宏观信息不进入技术模型，也不覆盖技术建议。
- **模型验证**：展示模型链路状态、可用的历史表现和预测留档。

## 技术架构

- Streamlit 前端
- FastAPI 后端
- Python 3.12 CPU 模型服务
- Docker Compose 本地编排
- 本机持久化设置与运行记录

## 本地启动

安装 Docker Desktop 后运行：

```bash
docker compose up --build -d
```

然后打开：

```text
http://127.0.0.1:8501/
```

首次使用时，可在网页设置中录入本机数据源密钥。未配置行情数据时，技术接口会返回真实的数据不可用状态，不会使用模拟行情代替。
